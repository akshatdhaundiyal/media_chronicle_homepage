# Video Showcase Directory

Place your Google Flow / Veo generated video here:
- **Filename**: `vault_scroll.mp4` (or `vault_scroll.webm`)
- **Path**: `assets/videos/vault_scroll.mp4`

When placed, Media Chronicle's scroll-scrubbed showcase will automatically detect the video and scrub smoothly with the visitor's scroll!
If the video is not present, a high-definition fallback canvas simulation runs automatically.
